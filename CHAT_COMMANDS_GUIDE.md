# AI Chat Commands Guide

## Task Management Commands

### ➕ Add Tasks
```
"Add a task to buy groceries"
"Create a task: finish project report by Friday"
"Add task: call mom with high priority"
```

### 📋 List & View Tasks
```
"Show me all my tasks"
"List pending tasks"
"What tasks do I have?"
"Show completed tasks"
```

### ✅ Mark Tasks Complete
```
"Mark task 2 as done"
"Complete task 5"
"Finish task 1"
```

### ✏️ Update Tasks
```
"Update task 1 title to buy milk"
"Change task 3 description"
"Rename task 5 to new name"
```

### 🎯 Set Priority
```
"Set task 2 priority to high"
"Mark task 3 as low priority"
"Change task 1 to medium priority"
```

### 🗑️ Delete Tasks
```
"Delete task 4"
"Remove task 2"
"Cancel task 7"
```

## Tips
- Always reference tasks by their **number/ID**
- You can combine actions: "Add a high priority task to study"
- Chat remembers your conversation context
- Check the **Dashboard** for visual task management

## Not Working?
- Make sure you're **logged in**
- Use the **Dashboard** to manually add/edit tasks
- Backend must be running on **port 8000**
